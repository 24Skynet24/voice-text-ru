# Voice Text RU

Текстовый редактор для Windows с распознаванием русской речи **полностью на вашем компьютере**.
Ни звук, ни текст никуда не передаются, интернет нужен только один раз — чтобы скачать модель.

```
┌──────────────────────────────────────────────────────────┐
│ Файл   Правка   Настройки   Справка                      │
├──────────────────────────────────────────────────────────┤
│ [Создать][Открыть][Сохранить]  [● Запись]                │
│ Микрофон: [ USB MIC PRO ▼ ]    ████████████░░░░          │
├──────────────────────────────────────────────────────────┤
│                                                          │
│  Сегодня я хочу рассказать о своём новом проекте         │
│  это приложение распознаёт русскую речь                  │
│  _прямо на компьютере_                                   │
│                                                          │
├──────────────────────────────────────────────────────────┤
│ ● Идёт запись          Сохранено в 14:32:05              │
└──────────────────────────────────────────────────────────┘
```

## Возможности

* Распознавание русской речи локально, без облачных сервисов и ограничений по времени.
* Текст появляется **во время речи** и уточняется по мере распознавания фразы.
* Вставка текста **с позиции курсора** — можно продолжить диктовать в середину документа.
* Запись продолжается, когда окно свёрнуто или неактивно.
* Глобальное сочетание клавиш (по умолчанию `Ctrl+Shift+Space`) — начать и остановить запись
  из любого приложения.
* Автосохранение во время записи: при аварийном завершении теряются максимум последние секунды.
* Обычный текстовый редактор: отмена, повтор, выделение, буфер обмена, UTF-8.
* Выбор микрофона и живой индикатор уровня сигнала.
* Выбор модели распознавания с понятным описанием компромиссов.

Чего в первой версии нет: автоматической расстановки знаков препинания сверх той, что даёт сама
модель, значка в области уведомлений и автозапуска вместе с Windows.

## Установка (для пользователя)

1. Скачайте и запустите `VoiceTextRU-1.0.0-setup.exe`.
2. Запустите «Voice Text RU».
3. При первом нажатии «Запись» программа скачает модель распознавания
   (по умолчанию около 2 ГБ: основная модель и быстрая модель для черновиков).
   Это происходит один раз; дальше приложение работает офлайн.

Модели и журналы хранятся в `%LOCALAPPDATA%\VoiceTextRU`. При удалении программы они остаются —
их можно удалить вручную.

Python, Node.js и другие инструменты разработчика устанавливать **не нужно**.

## Как пользоваться

1. «Создать» — выберите имя и папку для документа. Без документа запись не начнётся.
2. Поставьте курсор туда, где должен появиться текст.
3. Нажмите «● Запись» или `Ctrl+Shift+Space`.
4. Говорите. Серым курсивом показывается черновой текст — он уточняется и заменяется
   окончательным после паузы в речи.
5. Можно переключиться в браузер или другое приложение: запись продолжится.
6. Нажмите «■ Остановить» или сочетание клавиш ещё раз.
7. Поправьте текст и скопируйте его (`Ctrl+A`, `Ctrl+C` или «Правка → Копировать весь текст»).

### Если что-то пошло не так

| Признак | Что делать |
|---|---|
| Индикатор уровня не шевелится | Выберите другое устройство в списке «Микрофон»; проверьте доступ к микрофону в параметрах конфиденциальности Windows |
| Текст появляется с большой задержкой | Настройки → выберите модель поменьше (Medium или Small) |
| Сообщение «распознавание не успевает за речью» | То же: модель слишком тяжёлая для этого компьютера |
| Горячая клавиша не работает | Сочетание занято другой программой — выберите другое в настройках |
| Нужны подробности ошибки | Справка → «Открыть журнал работы» |
| Программа не запускается | Запустите проверку установки (см. ниже) |

### Проверка установки

Если приложение ведёт себя странно, выполните проверку: она загружает модель и
распознаёт файл, не открывая окна, и пишет отчёт в
`%LOCALAPPDATA%\VoiceTextRU\selftest.txt`.

```powershell
& "$env:ProgramFiles\VoiceTextRU\Voice Text RU.exe" --selftest
```

Отчёт показывает, какие микрофоны видит программа, используется ли видеокарта,
сколько потоков процессора задействовано и удалось ли загрузить модель.
Если добавить путь к файлу `.wav` (моно, 16 кГц), проверка ещё и распознает его —
это отделяет проблемы с микрофоном от проблем с распознаванием:

```powershell
& "$env:ProgramFiles\VoiceTextRU\Voice Text RU.exe" --selftest C:\путь\запись.wav
```

## Настройки

| Параметр | Назначение |
|---|---|
| Микрофон | Устройство ввода; выбор сохраняется по имени, а не по номеру |
| Модель | Точность против скорости, см. таблицу ниже |
| Быстрая модель | Маленькая модель, которая показывает черновой текст почти сразу |
| Вычисления | Автоматически / процессор / видеокарта NVIDIA |
| Пауза для фиксации фразы | Длительность паузы, после которой текст подтверждается |
| Интервал автосохранения | Как часто документ пишется на диск |
| Глобальная горячая клавиша | Сочетание для начала и остановки записи |

### Какую модель выбрать

Измерено на AMD Ryzen 5 7500F (6 ядер / 12 потоков), INT8, без видеокарты NVIDIA.
Время — длительность одного прохода распознавания; оно почти не зависит от длины фразы.

| Модель | Загрузка | Один проход | Качество на русском |
|---|---|---|---|
| Small | ~490 МБ | ~0.9 с | Путает «е» и «ё», ошибается в окончаниях |
| Medium | ~1.5 ГБ | ~2.9 с | Хорошее, но «ё» тоже теряет |
| **Large-v3-turbo** (по умолчанию) | ~1.6 ГБ | ~3.2 с | Лучшее из практичных |
| Large-v3 | ~3.1 ГБ | ~5.1 с | Эталонное, но для процессора тяжело |

Medium — невыгодный выбор: он почти так же медленный, как Large-v3-turbo, но заметно менее точен
(в проверочной фразе «о своём новом проекте» правильное «своём» дали только Large-v3-turbo и
Large-v3). Поэтому по умолчанию выбран Large-v3-turbo, хотя он и больше по размеру.
Подробное обоснование и измерения — в [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).

Задержка не зависит от длины фразы: кодировщик Whisper всегда обрабатывает окно в 30 секунд.
Поэтому черновой текст показывает отдельная быстрая модель, а основная подтверждает фразу целиком.

**Видеокарты AMD и Intel не ускоряют распознавание**: движок CTranslate2 поддерживает только
процессор и CUDA. На компьютерах с NVIDIA режим «Автоматически» сам задействует видеокарту.

## Для разработчика

### Требования

* Windows 10/11 (64 бита)
* Python 3.10–3.12

### Установка окружения

```powershell
git clone <repository> voice-text-ru
cd voice-text-ru

python -m venv .venv
.\.venv\Scripts\python.exe -m pip install --upgrade pip
.\.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
.\.venv\Scripts\python.exe -m pip install -e .
```

### Запуск в режиме разработки

```powershell
.\.venv\Scripts\python.exe -m voicetext_ru

# с подробным журналом
.\.venv\Scripts\python.exe -m voicetext_ru --verbose
```

### Тесты

```powershell
.\.venv\Scripts\python.exe -m pytest -q
```

Автоматические тесты не требуют микрофона и модели: движок распознавания подменяется заглушкой.
Сценарии, требующие живой речи, описаны в [docs/TESTING.md](docs/TESTING.md).

### Сборка production-версии

```powershell
powershell -ExecutionPolicy Bypass -File build\build.ps1
```

Скрипт выполняет три шага:

1. `build\make_icon.py` — рисует `build\app.ico`;
2. **PyInstaller** по файлу `build\voicetext_ru.spec` — собирает
   `dist\VoiceTextRU\Voice Text RU.exe` вместе со встроенным интерпретатором Python
   и всеми библиотеками;
3. **Inno Setup** по файлу `build\installer.iss` — собирает
   `dist\installer\VoiceTextRU-1.0.0-setup.exe`.

Шаг 3 пропускается, если Inno Setup 6 не установлен: приложение из `dist\VoiceTextRU`
работоспособно и само по себе, его достаточно скопировать на другой компьютер.
Установщик ставится в профиль пользователя и **не требует прав администратора**.

Полезные параметры:

```powershell
# только приложение, без установщика
powershell -ExecutionPolicy Bypass -File build\build.ps1 -SkipInstaller

# сборка другим интерпретатором
powershell -ExecutionPolicy Bypass -File build\build.ps1 -Python C:\Python312\python.exe
```

Модели распознавания **в сборку не входят**: они занимают гигабайты и скачиваются при первом
запуске в профиль пользователя. Благодаря этому установщик остаётся небольшим, а обновление
программы не требует повторной загрузки моделей.

### Структура проекта

```
src/voicetext_ru/
├─ app.py              точка входа
├─ controller.py       связывает потоки: звук → распознавание → интерфейс
├─ settings.py         настройки, сохраняемые между запусками
├─ audio/              перечисление устройств, захват, пересчёт частоты
├─ asr/                движок, определение пауз, потоковая обработка, фильтрация
├─ core/               документ, автосохранение, горячая клавиша, состояния
└─ ui/                 окно, редактор, вставка текста, индикатор, настройки
```

Архитектура и обоснование технических решений — [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).
